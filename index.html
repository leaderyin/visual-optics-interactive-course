CHAPTER 1

光的基本性質

先理解光怎麼走、速度如何改變，以及波長、頻率與能量之間的關係，後面的折射與成像才會有直覺。

一句話理解
光在均勻介質中近似直線前進；進入不同介質時，速度與波長會改變，但頻率保持不變。

折射率 Refractive Index

n = c / vc：真空光速；v：光在介質中的速度

折射率越高，代表光在該介質中傳播越慢。常見近似：空氣 1.00、水 1.33、一般玻璃約 1.50。

Exam Tip
光進入不同介質：頻率不變；速度與波長改變。

電磁光譜與光能量

可見光只是電磁光譜的一小段。對同一介質而言，光速固定，因此 v = λf；頻率越高，波長越短，單一光子的能量越高。

v = λ f　　E = h f
考點
短波（藍、紫）頻率較高、單一光子能量較高；長波（紅）相反。

光的二象性

干涉、繞射凸顯波動性；光電效應等現象則需要粒子（光子）觀點解釋。

針孔成像

依光直線前進與相似三角形形成倒立實像。孔徑變小可減少模糊、增加景深，但過小會因繞射使影像變差。

Exam Tip
「針孔成像為直立實像」是錯誤敘述；正確為倒立實像。

CHAPTER 2

折射率與 Snell’s Law

折射不是背「靠近法線／遠離法線」而已，而是比較兩側折射率與光速，再用 Snell 定律定量理解。

Snell’s Law 模擬器

折射角—
光線趨勢—
狀態—
一句話理解
由低折射率進高折射率：靠近法線；由高折射率進低折射率：遠離法線。

核心公式

n₁ sin θ₁ = n₂ sin θ₂

角度都是相對「法線」量，不是相對介面。

常見錯誤
入射角 0° 時，即使速度改變，光線方向不偏折。
為何折射率高會靠近法線？

光進入較高折射率介質後速度下降。由 Snell 定律，若 n₂>n₁，則 sinθ₂ 必須較小，因此 θ₂ 較小，更靠近法線。

Textbook Ch.1
Refraction

從方向判斷到定量計算

  • 所有角度均相對法線；入射角為 0° 時方向不偏折。
  • 低 n 進入高 n 靠近法線，高 n 進入低 n 遠離法線。
  • 先用方向建立直覺，再使用 Snell’s Law 計算折射角。
CHAPTER 3

臨界角與全反射

只有光從「高折射率」往「低折射率」前進時，才可能發生全反射。

臨界角模擬器

臨界角—

判斷條件n₁ > n₂

臨界角 Critical Angle

sin θc = n₂ / n₁　（n₁ > n₂）

當折射角剛好等於 90°，對應的入射角就是臨界角；再增加入射角，就沒有折射光進入第二介質，形成全反射。

Exam Tip
高 n → 低 n 才談得上臨界角與全反射。
Textbook Ch.1
Total Internal Reflection

全反射判斷三步驟

1. 方向必須由高折射率介質進入低折射率介質。
2. 臨界角θc=sin⁻¹(n₂/n₁)，只在 n₁>n₂ 時存在。
3. 比較θi>θc 才是全反射；相等時折射光沿介面前進。

Textbook Ch.3
The Vergence Relationship

聚散度解題流程

  • 物方：L=n/l；像方：L′=n′/l′，折射率取光線實際所在介質。
  • 光學面只改變聚散度：L′=L+F。
  • L′>0 為會聚光形成實像；L′<0 為發散光形成虛像；橫向放大率 ML=L/L′。
CHAPTER 5

球面折射

兩個介質之間只要有折射率差，加上曲率，就會產生屈光力。

一句話理解
折射率差越大、表面越彎（|r| 越小），球面的屈光能力越強。

球面屈光力

F = (n₂ − n₁) / r

r 以公尺代入。教材符號：曲率中心在頂點右側時 r 為正；在左側為負。

常見錯誤
公式分子應是 n₂ − n₁；教材掃描若出現 n₂ − n₂，屬明顯誤植。

球面成像的聚散度觀念

L′ = L + F

先把入射光轉成物方聚散度 L，再加上表面的屈光力 F，即得到像方聚散度 L′。若已知像方介質折射率 n′，可由 l′ = n′ / L′ 求像距。

考點
這種做法比硬背多套「物距像距公式」更適合視覺光學國考。

正負號判斷小工具

← 物／光源鏡左發散：L < 0
光學面 | ○ →圓心在右r > 0
→ 像／聚焦點鏡右會聚：L′ > 0
Textbook Ch.2
Spherical Surfaces

球面折射的四個核心

  • 光由左向右：圓心在頂點右側 r>0，左側 r<0。
  • 表面屈光力 F=(n′−n)/r；曲率越大（|r|越小），屈光力越強。
  • 平行光與主、次焦點；F=n′/f′=−n/f。
  • 會聚光形成可投影的倒立實像；發散光形成不可投影的正立虛像。

注意
厚度 t 必須以公尺代入。下列 Front/Back Vertex Power 採教材常用 paraxial thick-lens 關係。

Equivalent Power

Fₑ = F₁ + F₂ − (t/n)F₁F₂

描述整個厚透鏡對平行近軸光的等效屈光能力。

Back Vertex Power

Fᵥ′ = F₂ + F₁ / (1 − tF₁/n)

與遠用鏡片度數量測概念密切相關。

Front Vertex Power

Fᵥ = F₁ + F₂ / (1 − tF₂/n)

TEXTBOOK CHAPTER 5

多折射面光學系統

前一個光學面形成的像，會成為下一個光學面的物。距離傳遞與光線所在介質，是多透鏡題最容易出錯的兩點。

逐面解題演算法
求 L → 加上 F 得 L′ → 傳遞到下一面 → 將新的聚散度當成下一面的 L。
  1. 畫出光由左向右的簡圖並標示間距。
  2. 在第一片前求物方聚散度 L₁。
  3. L₁′=L₁+F₁；傳遞 d 後，L₂=L₁′/(1−dL₁′)。
  4. L₂′=L₂+F₂；由符號判斷最終實像或虛像。
  5. 總放大率為各面放大率相乘。

虛物 Virtual Object

若入射到下一光學面的光線原本正在會聚，但在抵達會聚點前先遇到下一面，該會聚點就是下一面的虛物。

虛物：入射光為會聚光，因此 L > 0
Exam Tip
不要只看物點畫在鏡片哪一側；要看抵達該面的光束究竟在發散還是會聚。
