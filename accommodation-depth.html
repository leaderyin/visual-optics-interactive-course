01 / ACCOMMODATION · pp.115–122

調節：讓近物重新落在視網膜上

先假設沒有景深。視網膜位置固定，不是靠眼球前後移動來追焦。

解題前先學 ①｜聚散度尺標：越靠近眼睛，越負

眼球表面取為原點。在空氣中，眼前物體的有號位置 u 為負，聚散度 U＝1/u。眼前 50 cm：u＝−0.50 m、U＝−2.00 D；眼前 10 cm：u＝−0.10 m、U＝−10.00 D；無限遠為 0 D。

U＝1/u　｜　眼前 u＜0 → U＜0若題目只寫「眼前距離 d＝10 cm」，d 是正的距離大小；先寫 u＝−d，再代 U＝1/u。所有尺標都使用有正負號的聚散度 U。
尺標把正聚散度展開在無限遠左側，方便看出「＋2 → 0 → −2 → −10 D」的連續變化。正聚散度實際對應眼後虛點／會聚入射光，不是空間中真的有「比無限遠更遠」的物體；此圖按 D 排列，不是等比例的公分位置圖。

解題前先學 ②｜加正往近、加負往遠；取下改用反號抵銷

先固定眼睛本身的屈光狀態與調節幅度，並把鏡片與眼放在同一參考平面。以下的「戴鏡後遠點」指眼＋鏡片系統可對焦的物方遠點；眼睛本身的放鬆遠點 R 不會被鏡片改寫。

物體聚散度 U ＋ 外加鏡片 F ＝ 眼睛所需入射聚散度
放鬆時：U遠點＋F＝R → U遠點＝R−F
最大調節時：U近點＝R−F−Amax加正鏡 ΔF＞0 → U 減少（往右、往眼前近處）；加負鏡 ΔF＜0 → U 增加（往左、往遠處）。真正調節幅度不變。
操作前操作後

「拿掉」模式假設原有鏡片組中確實包含指定鏡片，等效改變量是其反號：ΔF＝−F取下。跨過 0 D 後屬正聚散度虛點，不能把它當成眼前可閱讀距離。需要鏡眼距離時，改用第 03 節逐平面計算。

看近時的生理順序

  1. 睫狀肌收縮。
  2. 懸韌帶張力降低，不是「拉得更緊」。
  3. 水晶體變得較凸，前表面曲率增加。
  4. 眼的總屈光力增加，讓原本偏後的近物影像前移。

此為教學簡化；真實眼還有調節遲滯、像差與雙眼協調等因素。

把同一個 U＋F＝V 用到底

U ＋（F₀ ＋ A）＝ VU：眼前入射聚散度；F₀：放鬆眼屈光力；A：使用中的調節量；V：像方聚散度。

定義 R＝Vret−F₀，即放鬆眼的角膜平面遠點聚散度。要成像在視網膜：

U ＋ A ＝ R　⇒　A需求＝ R − U

這是把原眼屈光力 F₀ 移項後的等效調節式；不是說調節後出射光的總聚散度只有 R。

互動 1｜黑色放鬆眼，紅色調節後

預測：未矯正 −2 D 近視看 25 cm，需要 4 D，還是 2 D？

放鬆眼 A＝0目前使用的調節量固定視網膜

圖為軸上點的近軸示意，眼前與眼內使用不同縮放，眼內比例會自動調整以顯示焦點；同一張圖的視網膜位置固定；F₀＝60−R D、n′＝1.333、視網膜像方聚散度固定 +60 D。負的調節需求表示「必須比完全放鬆再減少屈光力」，不是可使用的負調節。

02 / FAR POINT & NEAR POINT · pp.123–125

遠點、近點與真正調節幅度

先分清「正在用」與「最多能用」

A：目前使用的調節量。
Amax：從完全放鬆到最大調節的屈光力增量。

放鬆眼：U遠點＝R。
最大調節：U近點＝R−Amax。

Amax＝UFP−U近點

沿用同一條有正負號的聚散度尺標

先把遠點放上尺標，再往「更負、靠近眼睛」方向走 Amax D，找到近點。調節幅度＝遠點聚散度−近點聚散度，不是把公分相減。

U遠點＝R
U近點＝R−Amax
位置 u＝1/U（m）

U＜0：眼前實物；U＝0：無限遠；U＞0：眼後虛點，在教學尺標上展開於無限遠左側。

互動 2｜相同幅度，不同明視位置

遠視的放鬆遠點在眼後，但只要調節幅度足夠，眼睛仍可能看清無限遠。不要把「虛遠點」誤解成「只能看眼後物體」，也不要把無眼前實近點顯示成負公分。
03 / SPECTACLES VS CONTACT LENSES · pp.125–130

眼鏡不在角膜上，必須分段計算

保持同一隻眼、同一物體位置與完整遠用矯正，比較矯正平面造成的差異。

互動 3｜先經鏡片，再傳到眼睛

先看長條，再記方向：誰需要較多調節？

沿用上方同一隻眼、同一角膜前物距與遠用全矯條件。切換近視／遠視，再拖曳頂點距離：長條越長，所需調節越多。

記憶線索：近視「框少」，遠視「框多」；鏡片貼到角膜，兩者相同。
「框少／框多」說的是看近的調節需求，不是眼睛本身的調節幅度。

立即檢核｜目前條件下，框架鏡需要的調節比隱形眼鏡……

請選一個答案；改變條件後可再判斷一次。

為什麼？從「遠用基準」看額外需求

兩種鏡片都已把遠處矯正清楚，因此比較的是從遠處轉看近物時，眼睛還需要增加多少屈光力。框架鏡與角膜之間的距離會改變傳到眼睛的聚散度；負鏡近視與正鏡遠視的影響方向不同。

當 v＝0，Fs＝R、Ueye＝−1/d＋R，所以 A＝R−Ueye＝1/d，兩者一致。比較鏡片度數大小，無法取代這個分段計算。

五步驟，不跳過鏡眼距離

  1. 全矯框架鏡：Fs＝R／(1＋vR)。
  2. 物距從角膜量起，鏡前距離為 d−v：Us＝−1／(d−v)。
  3. 通過鏡片：Us＋Fs＝Vs。
  4. 空氣中傳到角膜：Ueye＝Vs／(1−vVs)。
  5. 眼的調節：A＝R−Ueye。

v、d 都先換成公尺；本實驗兩種矯正都完全矯正遠用，不額外加入 ADD。

比較的結論有前提

同一角膜前物距、相同角膜屈光狀態、完整遠用矯正下：

  • 近視：框架鏡的調節需求通常小於隱形眼鏡。
  • 遠視：框架鏡的調節需求通常大於隱形眼鏡。
  • v＝0 時：兩者計算應完全一致。
不能只比較鏡片度數的絕對值；也不能把「需求增加」說成「眼睛的調節幅度被鍛鍊增加」。
04 / PRESBYOPIA & NEAR ADD · pp.130–132

近用加入度：降低需求，不增加能力

老視是隨年齡出現的調節能力下降；近視者也會老視，摘鏡能看近不代表沒有老視。

互動 4｜工作距離、調節儲備與 ADD

本節採遠用已全矯、忽略頂點距離的同一平面簡化模型。若需精確鏡眼距離換算，回到互動 3。

ADD模型＝max(0, 1/d − kAmax)k 為允許使用比例；眼睛的 Amax 不因 ADD 改變。

「使用一半幅度」是考題與初步估算的假設，不是所有人的驗配標準。實際需考量視覺需求、量測方式、雙眼功能與試戴；本教材不提供個人處方。

NRA／PRA：理解符號與簡化平衡法

NRA（negative relative accommodation）逐加正鏡、減少調節需求；PRA（positive relative accommodation）逐加負鏡、增加調節需求。名稱指調節方向，不是所加鏡片的正負號。

ADD新＝ADD暫定＋(NRA＋PRA)／2此式 NRA 用正數、PRA 用負數；限本節理想化平衡模型。

例如暫定 ADD +1.25 D、NRA +1.25 D、PRA −1.75 D，調整量＝−0.25 D，得到 ADD +1.00 D。

臨床 NRA／PRA 受集合、融合與景深影響，不可把兩者絕對值之和一律當成單眼真正調節幅度。
05 / BLUR CIRCLE, DEPTH OF FIELD & FOCUS · pp.199–205, 210–213

縮小模糊圈，不等於把焦點移回來

模糊圈 Blur circle

當幾何焦點不在視網膜上，光束在視網膜的截面形成模糊圈。離焦越多、瞳孔越大，幾何模糊圈通常越大。

針孔阻擋外圍光線，縮小模糊圈，但不替眼睛補足屈光力，也不直接增加調節幅度。

小瞳孔不是越小越好

瞳孔縮小會減少進光量；很小的孔徑也會使繞射變得顯著。不能用幾何光路圖推出「縮到零就最清楚」。

針孔視力改善可作為屈光性模糊的線索，不是單獨排除眼疾或弱視的診斷。

互動 5｜固定離焦，只改瞳孔

幾何模型：入射孔徑放在簡化眼折射平面，Vret＝60 D，b≈瞳孔直徑×|ΔV|／60。Airy 角半徑 θ＝1.22λ／孔徑（rad）；不可把角半徑直接當作模糊圈直徑相加。本圖不模擬實際視力，也不由瞳孔大小推定個人的景深。

互動 6｜物方景深與像方焦深

把容許離焦設定為 ±δ。此近軸固定屈光力模型中，兩者的屈光度寬度相同，公分／毫米寬度不相同。

總景深＝2δ；物方 U＝U₀±δ
像方 V＝60±δ；像距＝n′／Vn′＝1.333；物方先使用 D 運算，最後才換成距離。
06 / TRUE VS APPARENT AMPLITUDE · pp.205–207

把調節與景深放在同一條屈光度軸

先畫出真正可對焦的範圍，再在遠、近兩端各延伸 δ。綠色是調節；橘色是景深容許，不是額外的調節能力。

互動 7｜明視範圍整合

U真正遠點＝R−ADD；δ＝T／2
U可辨識遠界＝R−ADD＋δ
U可辨識近界＝R−ADD−Amax−δ

此節忽略頂點距離，所有量在同一參考平面。遠用全矯時 R＝0；裸眼則填原屈光狀態。圖中 U＞0 為正聚散度虛點區，會保留供推理，但不能當作眼前實物閱讀範圍。

反向例題｜用清晰遠近界還原真正幅度

限遠用全矯、透過同一 ADD、兩端皆為有限眼前距離的理想模型。

若已跨到無限遠，能觀察到的眼前距離區間被截斷，不能直接用「截斷後的聚散度寬度−總景深」還原真正幅度。題目說的「近點」究竟包含景深，也必須先釐清。
07 / HYPERFOCAL DISTANCE · pp.208–209

由超焦距離，反推總景深

超焦距離 H（亦稱泛焦距離）是仍可辨識無限遠時，最近的對焦距離，不是可辨識近界。H 寫距離大小（正值）；眼前的有號位置為 uH＝−H。

超焦距離所對應的聚散度絕對值，就是全景深（總景深 T）的一半。
先取倒數、保留眼前的負號，再取絕對值乘 2：H → UH＝−1/H → δ＝|UH| → T＝2|UH|。
|UH|＝δ＝T／2
總景深 T＝2|UH|＝2／H（D）H 必須以公尺代入。這個「一半」指屈光度（D）寬度，不是公尺／公分寬度。

本節採固定對焦、物方聚散度兩側各容許 ±δ 的對稱模型，且可辨識遠界恰好是無限遠 0 D。一般對焦距離不一定是 H；離開這些條件，不能直接用 T＝2/H。

互動 8｜改一個已知量，看兩個半段一起改變

三個欄位連動：可從超焦距離、對焦聚散度或總景深任一項開始。先預測：H 縮短一半，總景深會如何改變？

遠側半段 δ近側半段 δ

圖按 D 排列，兩段等長。焦點到無限遠、焦點到近界的公尺距離並不相等。距離欄 H＞0；無限遠請按「T＝0」。所有數值只是此對稱教學模型的換算，不是個人景深或視力的量測結果。

為什麼剛好是一半？從遠界 0 D 推導

  1. 固定對焦於 H，對焦聚散度 UH＝−1/H。
  2. 可辨識遠界＝UH＋δ；在超焦條件下，遠界恰好為 0 D。
  3. 所以 δ＝−UH＝|UH|＝1/H：這是單側。
  4. 還有同樣大的近側 δ，因此總景深 T＝δ＋δ＝2/H；可辨識近界 U＝UH−δ＝−T，距離大小＝1/T＝H/2。

例題｜先作答，再展開解析

以下皆採同一個對稱聚散度模型；遠界恰好為無限遠。

例題 1：H＝2 m，單側與總景深各是多少？
  1. uH＝−2 m，UH＝1/(−2)＝−0.50 D。
  2. 單側 δ＝|−0.50|＝0.50 D。
  3. 總景深 T＝2×0.50＝1.00 D。
  4. 近界 U＝−1.00 D，在眼前 1 m；對焦仍是 2 m，可辨識範圍是 1 m 至無限遠。

易錯：0.50 D 只是單側，不能當成總景深。

例題 2：H＝80 cm，總景深是多少？
  1. 先換單位：80 cm＝0.80 m。
  2. UH＝−1/0.80＝−1.25 D，單側 δ＝1.25 D。
  3. T＝2×1.25＝2.50 D。
  4. 近界 U＝−2.50 D，在眼前 0.40 m＝40 cm。

易錯：不能把 80 直接當公尺代入 2/H；景深的 D 寬度不帶負號。

例題 3：超焦對焦聚散度為 −0.40 D，能推論什麼？
  1. 單側 δ＝|−0.40|＝0.40 D。
  2. 總景深 T＝2×0.40＝0.80 D，不是 0.40 D 或 −0.80 D。
  3. H＝1/0.40＝2.50 m。
  4. 近界 U＝−0.80 D，在眼前 1.25 m；可辨識範圍為 1.25 m 至無限遠。

回查：遠界 −0.40＋0.40＝0 D；近界 −0.40−0.40＝−0.80 D。

延伸例題：H＝2 m、Amax＝4 D，調節後的可辨識近界在哪裡？

另加前提：遠用全矯、無 ADD，且各調節狀態維持相同 δ。這是在改變調節後求最近範圍，不是固定對焦於 H。

  1. 先由 H 推出 δ＝1/2＝0.50 D、T＝1.00 D。
  2. 最大調節時，真正近點聚散度為 −4 D，距離為眼前 25 cm。
  3. 只在近側加一個 δ：可辨識近界 U＝−4−0.5＝−4.50 D。
  4. 近界距離大小＝1/4.5≈0.2222 m＝22.22 cm。

易錯：近端只加單側 0.50 D，不加總景深 1.00 D；真正幅度仍是 4 D。固定對焦 H 時的近界 H/2＝1 m，回答的是另一個條件。
